# Conceptual Design System

The application adopts a high-density, high-information semantic design system geared purely toward laboratory realities rather than conversational consumer UX.

## 1. Typography & Hierarchy
* **Font Family:** Monospaced numerical values are absolute requirements for data tables to ensure perfect vertical column alignment of arbitrary decimals. Sans-serif elements handle generic headers.
* **Weights:** `Bold` exclusively isolates statutory configuration boundaries (like Max/Min labels). 
* **Avoidance:** Elaborate font pairings or heavily styled aesthetics tracking purely cognitive overhead. 

## 2. Status Color Paradigms
Color strictly communicates metrological realities, but MUST NEVER be the singular indicator of state (adhering to accessibility).
* **PASS (Green / Positive):** Combined with a `[✓ PASS]` explicit string. Identifies computations fully inside tolerances.
* **FAIL (Red / Critical):** Combined with a `[X FAIL]` explicit string. Statutory thresholds breached.
* **BLOCKED (Dark Grey / Slate):** A systemic scope abort. The route mathematically cannot continue.
* **WARNING (Yellow / Caution):** Sub-optimal configuration flags (e.g. attempting to submit without entering $\Delta L$).

## 3. Interactive Inputs
* Input bounding boxes possess aggressive active focusing rings (e.g. 2px Blue) preventing users from losing keystroke-tracking position inside complex spreadsheet-style arrays.
* Tab-indexing explicitly jumps laterally across a row before progressing vertically. 

## 4. Separation Lines
* Visual spacing: High-density compact lines in testing matrices minimize vertical scrolling.
* Hard separators (e.g. solid vertical borders) literally divide raw entry DOMs to the left from derived calculated outputs to the right. 

## 5. Animation Constraints
* **Animations exist strictly as state-change verifiers** (e.g. confirming a `Saved` transition flash). No decorative loaders or bouncing modals are allowed. Professionalism assumes speed and visual stability above engagement metrics.
