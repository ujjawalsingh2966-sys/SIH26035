# Phase 14 - Reviewer Guide (Quality Officer / Certifier)

## 1. Review Queue
Access the **Pending Reviews** dashboard to inspect test cases submitted by laboratory technicians.

## 2. Evaluating Compliance
- Inspect calculation outputs, maximum permissible errors (MPE), and error standard deviations.
- Check that all OIML R76-1:2006 rule conditions evaluate to **PASS**.

## 3. Workflow Decisions
- **Return for Retest**: Provide feedback comments if data is incomplete or out of bounds.
- **Approve**: Transition the record to **APPROVED** state, locking all test observations from further modification.

*Disclaimer: Application workflow approval constitutes internal data verification and does not replace official statutory legal metrology certification.*
