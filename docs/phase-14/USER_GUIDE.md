# Phase 14 - Laboratory User Guide (Technician)

## 1. Authentication
Access the application portal using your assigned technician credentials to obtain an active session JWT token.

## 2. Test Case Creation
Navigate to **Test Cases** -> **New Evaluation**.
Enter:
- Target Instrument Serial & Model
- Laboratory Environmental Conditions (Temperature, Humidity)
- Verification Class (Class I, II, III, IIII)

## 3. Recording Observations
Record metrological readings for:
1. **Weighing Accuracy Test** (Ascending and Descending loads)
2. **Eccentricity Test** (Off-center loading across quadrants)
3. **Repeatability Test** (Successive loads at constant mass)
4. **Tare Test** (Subtractive tare validation)
5. **Zero-Setting Test** (Zero-tracking and zero-setting band)

## 4. Submitting for Review
When all required tests are completed and calculations verified, submit the record into the **UNDER_REVIEW** state.
