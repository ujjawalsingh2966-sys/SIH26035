# Phase 14 - Known Limitations & Non-Functional Boundaries

1. **Supported Instrument Scope**: Restricted strictly to Non-Automatic Weighing Instruments (NAWI). Automatic Weighing Instruments (AWI) are unsupported.
2. **Rule Standard**: Current implementation targets OIML R 76-1:2006. Other national variances (e.g. NIST Handbook 44) require future configuration profiles.
3. **Document Store**: The Pilot environment uses local persistent file-based JSON stores; distributed enterprise relational clustering is targeted for future phases.
4. **Statutory Status**: Generates prototype test reports pending formal statutory laboratory accreditation.
