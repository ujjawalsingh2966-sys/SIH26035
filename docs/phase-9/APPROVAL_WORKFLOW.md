# Phase 9: Approval Workflow

## 1. Context
Approval represents the terminal condition for a Test Case lifecycle mapping to successful regulatory verification.

## 2. Process
1. Data collection is completed by the Technician.
2. The technician executes `submitForReview`. Status moves to `READY_FOR_REVIEW`.
3. An authorized Reviewer executes `startReview`. The application stamps `reviewerId` identifying the reviewer who claimed the test case. Status becomes `UNDER_REVIEW`.
4. The reviewer reviews all captured `ObservationRecord`s and the compliance calculations generated by the Phase 6/7/8 engines.
5. If everything meets criteria, the Reviewer executes `approve`.

## 3. Results of Approval
- Submits an `action: 'APPROVE'` log into the audit ledger.
- Finalizes status to `APPROVED`.
- Triggers locking mechanisms blocking further modifications to the underlying `testCase`, `laboratoryConditions`, and `ObservationRecord` payloads.
